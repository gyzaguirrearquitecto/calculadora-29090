Calculadora (plantilla)

Esta versión es un MVP: estructura los tipos de procedimientos y tipologías (FUE/FUHU) y aplica reglas básicas (p. ej. método para estimar valor de obra). La determinación normativa final de modalidad requiere parámetros adicionales del proyecto y verificación con el reglamento vigente.

1) Selección

Para remodelación / refacción / acondicionamiento / puesta en valor, el FUE usa presupuesto estimado.

2) Resultado

Selecciona un procedimiento y calcula para ver resultados.

Licencias (Observatorio – demo)

Este módulo lee un CSV (demo) y permite filtrar por desplegables. Para usar datos reales, reemplaza data/licencias_sample.csv por un dataset normalizado con las mismas columnas.
